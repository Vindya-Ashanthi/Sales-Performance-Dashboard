# Sales-Performance
Power BI Sales Dashboard Project

## 📊 Project Overview
This project analyzes sales performance using Power BI.

The dashboard provides insights into:
- Total Sales
- Sales by Region
- Sales by Year
- Sales by Products

---

## 📁 Tools Used
- Power BI
- DAX
- Data Modeling
